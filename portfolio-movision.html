Case: Movision

Full Stack & HealthTech

Movision - Dashboard web sincronizado a fisioterapia em VR

Produto para fisioterapia que conecta uma experiência em VR ao dashboard do profissional, com dados de sessão, histórico do paciente, APIs e autenticação.

Dashboard, dados de sessão e integração com experiência VR

2025 Full Stack, Dashboard & Dados Movision

O Movision é um projeto de fisioterapia que utiliza VR sincronizado a um dashboard web para o fisioterapeuta acompanhar sessões, analisar dados e consultar informações daquele paciente ao longo do tratamento.

Visão geral

Minha atuação foi full stack: desenvolvi o front-end do dashboard com foco em análise de dados e clareza de leitura, implementei APIs para envio e recebimento de informações do banco, trabalhei com autenticação e também contribuí em partes da experiência/jogo em VR.

O produto conecta dados coletados durante a sessão ao acompanhamento do profissional, ajudando a transformar a experiência interativa em informação útil para avaliação e tomada de decisão.

Destaques do projeto

  • Dashboard web para acompanhamento de pacientes e sessões
  • Visualização e análise de dados coletados durante a fisioterapia
  • APIs para envio e leitura de dados do banco
  • Fluxos de autenticação para acesso à plataforma
  • Sincronização entre experiência VR e painel do fisioterapeuta
  • Contribuições pontuais no jogo/experiência interativa

Implementação técnica

A implementação exigiu cuidado com fluxo de dados, autenticação, persistência, estados de sessão e apresentação das informações clínicas de maneira objetiva. A interface precisava ser rápida de interpretar, porque o dashboard existe para apoiar o fisioterapeuta durante e depois da sessão.

Nesse projeto, o front-end não era só uma camada visual: ele era a ponte entre a experiência em VR, os dados coletados e a leitura prática do fisioterapeuta.

O resultado é um produto onde interface, APIs, autenticação, banco de dados e experiência interativa trabalham juntos para apoiar reabilitação e acompanhamento profissional.
