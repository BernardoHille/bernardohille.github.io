Case: COPEL + PUCPR

Pesquisa & indústria

COPEL + PUCPR - Monitoramento em tempo real para subestações elétricas

Interfaces para leitura, calibração e visualização de dados de sensores em ambiente embarcado, com foco em clareza, velocidade e uso técnico em campo.

Interfaces embarcadas para dados de sensores em tempo real

2021 UI embarcada, sensores & pesquisa aplicada COPEL + PUCPR

Desenvolvimento de interfaces para um sistema de monitoramento em tempo real de sensores aplicados a subestações elétricas, em projeto de pesquisa e indústria realizado em parceria com COPEL e PUCPR.

Visão geral

Atuei na criação de telas e protótipos de interface com foco em clareza, velocidade de exibição dos dados e usabilidade em ambiente embarcado, considerando as limitações de processamento e memória da placa.

O projeto envolveu desenvolvimento de UI com JavaScript em etapas de prototipação, além de implementação e adaptação para uma placa STM32, utilizando C e comunicação via DNP3 para leitura e exibição de dados de sensores.

Destaques do projeto

  • Prototipação de telas para leitura e calibração de sensores
  • Interface pensada para baixa latência e leitura técnica rápida
  • Adaptação da UI para limitações de processamento e memória
  • Implementação em placa STM32 com C
  • Comunicação DNP3 para leitura e exibição de dados

Implementação técnica

O trabalho conectou prototipação de interface, documentação técnica e desenvolvimento embarcado. A interface precisava ser objetiva, previsível e eficiente, exibindo informações de sensores de forma clara em um equipamento com recursos limitados.

Esse case foi uma ponte direta entre interface, sistemas embarcados e pesquisa aplicada: desenhar telas significava pensar também em memória, processamento, leitura técnica e confiabilidade.
